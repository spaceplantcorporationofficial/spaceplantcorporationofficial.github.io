FAQ

Is my API key safe?

It never leaves your machine. ASC Pilot signs a short-lived token locally with the openssl that ships with macOS and calls only Apple's API. The core is open source — read it.

What API key role do I need?

App Manager covers apps, versions, IAPs and availability. Add Sales (or use Admin) for the Money view.

Does it change anything in my account?

No. ASC Pilot is read-only. It tells you (or your agent) exactly what to fix and how.

Does it estimate revenue?

Never. Money comes from Apple's daily Sales reports, per currency, exactly as Apple publishes them. Days without a report are shown as missing — not filled in.

How is the license delivered?

After checkout you receive a key by email. Run ascpilot license activate <KEY>. Verification is offline (Ed25519).
